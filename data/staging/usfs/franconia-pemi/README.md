# USFS Franconia-Pemigewasset Staging Data

This directory contains raw USDA Forest Service trail GIS features downloaded from the ArcGIS query API inside an approximate Franconia/Pemigewasset ingestion envelope.

This is source GIS data only. It is not a navigational product, not an AMC White Mountain Guide challenge inventory, and not human verified for White Mountains Redline completion.

- Source features: 520
- Named features: 520
- Unnamed features: 0
- Unique trail names: 376
- Malformed/skipped features: 0
