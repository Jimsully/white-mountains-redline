# IP, Naming, and Data Notes

This is a product-development checklist, not legal advice.

## Product positioning
Use an independent product name such as "White Mountains Redline". Do not present it as an official AMC application or imply endorsement.

## Do not copy
- AMC guide prose/descriptions.
- AMC map artwork/cartography.
- Scans/photos of copyrighted guide pages.
- Branding that could imply official affiliation.

## Challenge inventory
Facts such as trail names and observed trail geometry are different from copyrighted prose/artwork, but an exact published compilation can raise separate selection/arrangement questions. Treat an edition-specific "every trail in this book" dataset as a review item before broad public distribution.

## Safer build strategy
- Build geographic linework from public/open sources.
- Write original trail copy.
- Store provenance.
- Keep challenge rules/versioning separate from the raw geographic database.
- Consider requesting AMC permission/cooperation before marketing an edition-specific official-looking challenge.

## OSM
If OpenStreetMap data is incorporated into the production database, track the ODbL implications and provide required attribution. Do not casually merge OSM-derived database content into a differently licensed public database without reviewing compatibility.
